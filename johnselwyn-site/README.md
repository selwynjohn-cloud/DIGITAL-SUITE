# John Selwyn — personal website

Personal site for **John Selwyn** — *Secure Your Peace of Mind*.

This is **not** Agile DIGITAL-SUITE. It is a separate personal front door, with its own look and voice.

## Local preview

Open `index.html` in a browser, or:

```bash
cd johnselwyn-site
python3 -m http.server 5173
```

Then visit http://localhost:5173

## Deploy to johnselwyn.com

1. Create a repo (recommended): `selwynjohn-cloud/johnselwyn-site`
2. Copy this `johnselwyn-site/` folder into that repo (or deploy this folder from Vercel)
3. In Vercel: **Add New Project** → import the repo → Root Directory = `johnselwyn-site` (if nested)
4. Point GoDaddy DNS for `johnselwyn.com` / `www` to Vercel (replace the current Website Builder hosting)
